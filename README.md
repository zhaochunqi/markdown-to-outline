# Markdown to Outline Converter

This project is a Next.js application that converts Markdown content to an outline format.

## Features

- Convert Markdown to outline
- Real-time preview
- Customizable outline options
- Responsive design

## Getting Started

### Prerequisites

- Node.js (version 20 or later)
- npm or yarn

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/your-username/markdown-to-outline.git
   ```

2. Install dependencies:
   ```
   pnpm install
   ```

3. Run the development server:
   ```
   pnpm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## Usage

1. Enter your Markdown content in the input area.
2. The outline will be generated automatically in the preview area.
3. Adjust the outline options as needed.
